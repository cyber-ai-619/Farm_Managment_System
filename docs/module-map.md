# Module Map

| Module | Folder | Suggested first task |
| --- | --- | --- |
| Farm and field | `backend/src/Modules/farm_field` | Design farm, field, and plot data structure |
| Crop | `backend/src/Modules/crop` | Model crops, varieties, and planting cycles |
| Irrigation | `backend/src/Modules/irrigation` | Define irrigation schedules and water tracking |
| Livestock | `backend/src/Modules/livestock` | Model animals, health, and production records |
| Inventory | `backend/src/Modules/inventory` | Define stock items and stock movement |
| Equipment | `backend/src/Modules/equipment` | Register machines and maintenance history |
| Labour | `backend/src/Modules/labour` | Track workers, attendance, and tasks |
| Pest and disease | `backend/src/Modules/pest_disease` | Record scouting and treatment events |
| Weather | `backend/src/Modules/weather` | Prepare weather data storage and API hooks |
| Harvest | `backend/src/Modules/harvest` | Capture harvest quantities and quality |
| Sales and market | `backend/src/Modules/sales_market` | Model orders, buyers, and pricing |
| Finance | `backend/src/Modules/finance` | Track income, costs, and profit reports |
| Suppliers and procurement | `backend/src/Modules/suppliers_procurement` | Register suppliers and purchase orders |
| Storage | `backend/src/Modules/storage` | Manage warehousing and post-harvest stock |
| Analytics | `backend/src/Modules/analytics` | Define dashboard metrics and charts |
| Notifications | `backend/src/Modules/notifications` | Design alerts and reminder triggers |
| Security | `backend/src/Modules/security` | Plan authentication, roles, and audit logs |
